# Contributing to Awesome Voice AI

## Adding a Tool

### Option 1: Open an Issue
Use the [Submit a Tool](https://github.com/ALLBOTSIO/awesome-voice-ai/issues/new?template=submit-tool.yml) template.

### Option 2: Pull Request
1. Fork this repo
2. Add the tool to the appropriate section in README.md
3. Follow the existing table format
4. Submit a PR

## Guidelines
- Tool must be directly related to voice AI
- Include a factual one-line description (no marketing language)
- Open source tools: include star count and license
- Commercial tools: include key differentiators
- No affiliate links
- Alphabetical order within subsections (open source vs commercial)

## Pull Request Checklist

Maintainers check every submission against this list. PRs that meet it are merged; PRs that don't are closed with a short reason.

- [ ] **Voice AI first.** The product or project is primarily about voice (speech synthesis, recognition, cloning, voice agents, telephony for voice agents, voice analytics, or voice MCP servers). General chatbots, SaaS directories and tools where voice is a minor feature don't qualify.
- [ ] **Link resolves.** The URL loads (HTTP 200) and points to the product, docs or repository, not a tracking or affiliate link.
- [ ] **Right section.** It sits in the existing section that fits best. New top-level sections are not opened for a single product.
- [ ] **Table format.** The row has the same columns as the rest of that table, with a factual one-line description (no marketing superlatives).
- [ ] **Open source details.** Open-source entries give an approximate star count and the license.
- [ ] **Not a duplicate.** The tool isn't already listed in that section (search README.md first).
- [ ] **One tool per PR**, or a tool plus its own MCP server.
- [ ] **Up to date with `main`.** Keep "Allow edits by maintainers" on so we can resolve conflicts for you.
